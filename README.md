# Pranostratic

An XMind mind map of the origin and genealogy of languages under the Nostratic hypothesis: a tree
from a proposed Pra-Nostratic (Nostratic, Borean) ancestor down to language families, branches,
individual languages and dialects. Useful for linguistics enthusiasts and students exploring
macrofamily classifications. Node labels are in Russian.

## Contents

`origin.of.languages.xmind` (XMind 3 format, about 1,100 nodes) covers:

- Western Nostratic: Afroasiatic (Egyptian, Berber, Chadic, Cushitic, Omotic, Semitic),
  Indo-European (Aryan incl. Indo-Iranian, Greek–Phrygian–Armenian, Paleo-Balkan, Balto-Slavic, Germanic,
  Venetic, Italic, Celtic, Tocharian, Anatolian) and Kartvelian.
- Eastern Nostratic: Altaic (Turkic, Mongolic, Tungus–Manchu, Japanese–Ryukyuan, Korean), Dravidian, Uralic and
  Eskimo-Aleut.

Extinct languages are marked with `†`; uncertain groupings carry a `?`. The Nostratic macrofamily is
a contested hypothesis, and this tree is a personal compilation, not a consensus classification.

## Usage

Open `origin.of.languages.xmind` in [XMind](https://xmind.com). Without XMind, the tree is stored
as XML in `content.xml` inside the file, which is a ZIP archive:

```sh
unzip -p origin.of.languages.xmind content.xml
```
